## Prerequisites

You need Node.js 24.16 or newer, a FreshRSS instance with Google Reader API access, an Ollama server with an embedding model, and a Qdrant server. Processor stores its own configuration and grouping state in SQLite.

<Steps>
  <Step title="Install dependencies">
    ```bash
    git clone https://github.com/bludesign/processor.git
    cd processor
    npm ci
    ```
  </Step>
  <Step title="Create local configuration">
    ```bash
    cp .env.example .env
    openssl rand -base64 32
    ```

    Put the generated value in `NEXTAUTH_SECRET`. Set `DATABASE_URL`, `NEXTAUTH_URL`, and the FreshRSS, Ollama, and Qdrant variables described in [Environment variables](/reference/environment-variables).
  </Step>
  <Step title="Start Processor">
    ```bash
    npm run dev
    ```

    Open `http://localhost:3000`. Processor redirects a new database to the setup page.
  </Step>
  <Step title="Create the first administrator">
    Enter a name, email address, and password. The setup mutation works only while the user table is empty. After it succeeds, sign in with the account you created.
  </Step>
  <Step title="Connect services">
    Open **Ollama Servers** and **Qdrant Servers** first, then add a **FreshRSS Server** that selects both. Environment-backed services appear automatically when their required variables are set.
  </Step>
  <Step title="Process subscriptions">
    Open the dashboard, select the FreshRSS server, and click **Process Feeds**. Use **Processor Status** for live stage-by-stage activity and **Feed Items** or **Article Groups** to inspect the result.
  </Step>
</Steps>

## Docker Compose

```bash
docker compose up --build
```

The included Compose file persists SQLite at `/processor/dev.db`. Supply production secrets and reachable service URLs before exposing the application outside your machine.

<Warning>
  Keep `NEXTAUTH_SECRET`, `GROUPED_FEED_SECRET`, and `WEBSUB_ENCRYPTION_KEY` stable. Rotating them invalidates sessions, signed feed URLs, or encrypted subscriber secrets respectively.
</Warning>
