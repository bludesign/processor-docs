## Purpose

Folder headers on **Subscriptions** connect FreshRSS categories to Processor's processing and grouping policy. You can configure each folder while editing its subscriptions on the same page. The former `/folders` landing page redirects to **Subscriptions**.

## Prerequisites and permissions

Configure and select a FreshRSS server first. All signed-in users can manage folder settings. Similarity grouping also requires reachable Ollama and Qdrant servers.

## Normal workflow

1. Open **Subscriptions** and find a folder. Its processing selector remains visible even when the folder is collapsed.
2. Choose **Similarity Grouping** where duplicate or related coverage is useful.
3. Click **Configure Grouping Settings** to open the dialog and set the similarity threshold, time window, publish delay, and lookback.
4. Click **Save Settings**, then **Run Grouping Now** or **Clear & Reprocess**.
5. Copy, open, or preview the generated Atom URL when grouping is enabled.

Use the folder's actions menu to add a subscription, rename the folder, or delete it. See [Subscriptions](/processing/subscriptions) for management, history synchronization, and retry behavior. A new folder requires its first subscription. Deleting a folder moves its feeds to FreshRSS's default folder; renaming a folder issues new Atom URLs and retires its previous WebSub resources.

## Important controls and behavior

- **Similarity Threshold** ranges from `0` to `1`; higher values demand closer embeddings.
- **Time Window (hours)** ranges from `1` to `720` hours and limits which articles can be compared.
- **Publish Delay (minutes)** ranges from `0` to `1440` minutes and allows late-arriving coverage to accumulate before publication.
- **Lookback Limit (days)** ranges from `1` to `3650` days; an empty value means no explicit day limit.
- **Run Grouping Now** processes the folder with current state. **Clear & Reprocess** deliberately rebuilds its derived grouping state.

## Failure states

Grouping remains empty when the folder has no eligible content, embeddings cannot be generated, Qdrant is unavailable, or the configured threshold is too strict. A missing Atom URL normally means grouping is disabled or no public feed identifier has been created.

## Operational notes

Change one grouping parameter at a time and compare results. Clearing derived state is destructive to existing group assignments, so use the [grouping debugger](/processing/folder-debug) before rebuilding a large folder.
